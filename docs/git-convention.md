# 커밋 컨벤션

이모지 + 타입 + 설명 형식을 씁니다.

```
:이모지코드: 타입: 설명
```

예시:

```
:sparkles: feat: 프로젝트 생성
:hammer: refactor: 리팩토링
:ambulance: fix: 에러 수정
```

- 설명은 한글, 명령형/현재형으로 짧게 (예: "~함", "~추가" 대신 "~추가함"보다는 "~추가"처럼 간결하게)
- 커밋 하나에 하나의 목적만 담기

## 타입 목록

| 이모지 | 코드 | 타입 | 설명 |
| --- | --- | --- | --- |
| ✨ | `:sparkles:` | `feat` | 새로운 기능 추가 |
| 🔨 | `:hammer:` | `refactor` | 동작 변경 없는 코드 리팩토링 |
| 🚑 | `:ambulance:` | `fix` | 에러/버그 수정 |
| 📝 | `:memo:` | `docs` | 문서 추가/수정 |
| 💄 | `:lipstick:` | `style` | UI/스타일 변경 (로직 변경 없음) |
| ✅ | `:white_check_mark:` | `test` | 테스트 추가/수정 |
| 🔧 | `:wrench:` | `chore` | 설정, 빌드 스크립트 등 잡일 |
| 📦 | `:package:` | `deps` | 패키지/의존성 추가·업데이트 |
| ⚡️ | `:zap:` | `perf` | 성능 개선 |
| 🚚 | `:truck:` | `move` | 파일/폴더 이동, 이름 변경 |
| 🔥 | `:fire:` | `remove` | 코드/파일 삭제 |
| ⏪️ | `:rewind:` | `revert` | 이전 커밋 되돌리기 |
| 🚧 | `:construction:` | `wip` | 작업 중 (미완성 커밋) |

필요한 타입이 더 있으면 이 표에 추가해서 씁니다.
